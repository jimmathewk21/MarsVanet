# results/ — freshly generated measurements

Files in this directory are produced by running the benchmark scripts on the
current machine. They are kept **separate** from `../final_evidence/`, which
holds the project's committed historical evidence, so that re-running a
benchmark never overwrites previously committed results.

Generated by:

| File                                 | Script                              |
|--------------------------------------|-------------------------------------|
| `paillier_benchmark.csv`             | `scripts/save_paillier_results.py`  |
| `multi_observer_benchmark.csv`       | `scripts/benchmark_multi_observer.py` |
| `trust_aggregation_comparison.csv`   | `scripts/compare_trust_aggregation.py` |

All three scripts honour `BENCH_OUTPUT=/path/to/file.csv` to write elsewhere.

These are **cryptographic micro-benchmarks only** (encryption / aggregation /
decryption timing with small demonstration keys). They are not network
performance results and say nothing about live detection or mitigation.

The numbers currently in this folder were measured with a small (~256-bit)
demonstration key and are not representative of production key sizes. Re-run
with a realistic key to measure that, e.g.:

```
python3 Methodology2/scripts/save_paillier_results.py 2048 50
```
