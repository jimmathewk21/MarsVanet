# MarsVanet dependencies
# =======================
#
# The runtime-independent logic (Paillier crypto, privacy-preserving
# aggregation, DoS-evidence scoring, mobility-aware detection and the
# progressive-mitigation decision state machine) and ALL of its unit tests use
# only the Python standard library. There is nothing to pip install to run:
#
#     bash Methodology2/run_tests.sh
#
# (The original code imported `sympy` for prime generation in
# paillier_crypto.py; that dependency has been removed in favour of a
# standard-library Miller-Rabin generator, so the crypto tests run anywhere.)
#
# ---------------------------------------------------------------------------
# The live SDN + mobility experiments need external runtimes that are NOT
# Python packages and cannot be installed with pip alone. They require a Linux
# host/VM with kernel networking privileges:
#
#   - Open vSwitch (ovs-vsctl, ovs-ofctl)        OpenFlow 1.3 switches
#   - Mininet-WiFi                               wireless topology emulation
#   - Ryu                                        SDN controller framework
#   - SUMO (sumo, sumo-gui, netconvert) + TraCI  mobility simulation
#
# Typical install on Debian/Ubuntu:
#   sudo apt-get install openvswitch-switch sumo sumo-tools
#   # Mininet-WiFi: https://github.com/intrig-unicamp/mininet-wifi
#   # Ryu (Python 3): pip install ryu   (pin an eventlet-compatible version)
#   export SUMO_HOME=/usr/share/sumo
#
# Only these Python packages are pip-installable and only needed on the live
# testbed (left unpinned here because exact versions depend on the VM image):
#
# ryu
# traci
#
# mininet-wifi is installed from its repository, not from PyPI.
